# STRIDE OS 对话与计划弹窗修复日志（2026-11-03）

## 问题

1. Agent 运行完成后，“模型行为”轨迹面板仍然保持展开，持续占用对话区域高度。
2. 训练计划预览需要在轨迹中再次点击，写入成功后确认弹窗和轨迹中的确认按钮没有完整清理。

## 修改

### 模型行为轨迹

- 新增“隐藏”按钮，可随时手动收起轨迹。
- Agent 成功完成 900 ms 后自动隐藏轨迹并清空步骤。
- 失败和取消时保留轨迹，方便查看错误和重试。
- 切换会话、新建会话和清空对话时同步隐藏旧轨迹。
- 成功运行不再显示无意义的“重试”按钮。

### 训练计划确认

- 计划预览生成后，在 Agent 完成时直接打开独立确认弹窗。
- 写入成功后立即关闭确认弹窗。
- 关闭后重置确认勾选、写入按钮和待处理计划状态。
- 写入成功后清空当前轨迹，并把轨迹内的确认按钮标记为“已写入训练日历”。
- 弹窗原生 `close` 事件也会重置状态，避免下次打开时残留旧状态。

## 行为说明

- 正常对话完成后不会留下模型行为面板。
- 失败的运行仍保留行为轨迹，以便定位问题和重试。
- 训练计划写入成功后，确认弹窗自动消失。
- 现有训练数据、模型配置和计划内容不受影响。
